# 文章管理迷你系统

## 功能介绍

这是一个基于 Flask 的文章管理迷你系统，包含以下功能：

1.  **用户认证**: 固定账号登录/登出 (admin / admin123)
2.  **文章管理**: 新建、编辑、删除、发布/取消发布文章
3.  **搜索分页**: 支持按标题搜索文章，分页展示（每页10条）
4.  **主题切换**: 支持 Light/Dark 两种主题模式
5.  **表单验证**: 标题和内容必填校验，标题长度限制1-120字符
6.  **消息提示**: 使用 flash 消息展示操作结果
7.  **前后台分离**: 前台展示已发布文章列表和详情，后台进行文章管理

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 启动应用

```bash
python app.py
```

访问地址：
- 前台首页: http://localhost:5000/
- 后台登录: http://localhost:5000/login

测试账号：
- 用户名: admin
- 密码: admin123

### 3. 运行测试用例

```bash
pytest test_articles.py -v
```

测试用例包含：
1.  登录功能测试（成功/失败）
2.  未登录访问后台权限控制测试
3.  文章创建与列表展示测试
4.  文章标题搜索功能测试
5.  文章发布状态切换测试
6.  文章删除后访问控制测试
7.  表单验证测试

## 使用说明

### 后台管理
1.  访问 `/login` 登录后台
2.  进入后台后可以查看所有文章列表
3.  点击「新建文章」创建新文章
4.  可以对文章进行编辑、删除、发布/取消发布操作
5.  使用搜索框可以按标题关键词搜索文章

### 主题切换
- 点击页面右上角的主题切换按钮，可以在亮色/暗色主题之间切换
- 主题选择会保存在 session 中，刷新页面会保持选择

### 前台访问
- 首页 `/` 展示所有已发布的文章
- 点击文章标题或「阅读全文」按钮可以查看文章详情
- 仅已发布状态的文章会在前台显示

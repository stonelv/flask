ADR-000: Template
=================

Status
------

Template — use this as a starting point for new ADRs.

Context
-------

Describe the forces at play: technical, political, social, project
constraints. This section describes the issue motivating the decision.

Decision
--------

The change that we're proposing or have agreed to implement.

Consequences
------------

What becomes easier or more difficult as a result of this decision.
List both positive and negative consequences.

Architecture Decision Records
=============================

These records capture the architectural decisions behind the production
observability and release-governance engineering platform added to this
repository. Each ADR is self-contained prose: the context that drove the
decision, the decision itself, and its consequences.

New ADRs are added (never rewritten in place); superseded ones are marked
``Status: superseded`` and left in place. See :doc:`0005-adr-process` for the
workflow.
